<USER_REQUEST>
Build a complete, modern, production-ready full-stack web application called **“AirIndex India”** based on the following problem statement:

**Development of a Real-Time Airfare Price Index for India through Automated Web Scraping of Permitted Airline and Online Travel Sources.**

The platform should collect, clean, analyze and visualize Indian domestic airfare data and calculate a Real-Time Airfare Price Index.

The application must use **only an SQL database** for persistent data storage. Do not use MongoDB, Firebase Firestore, Redis as a database, or any NoSQL database.

---

# 1. MAIN OBJECTIVE

Create a web platform that:

* Collects airfare data from permitted airline and OTA sources.
* Stores raw and processed airfare observations in an SQL database.
* Supports important Indian domestic routes.
* Tracks multiple advance-booking windows:

  * T+1
  * T+7
  * T+15
  * T+30
  * T+45
* Cleans and normalizes collected data.
* Calculates a weighted Airfare Price Index.
* Displays daily, weekly and monthly index values.
* Provides route-wise and airline-wise analytics.
* Provides authorized API access.
* Supports historical data and approximately 30-day back-testing.
* Provides a professional interactive dashboard.

# 4. EMAIL OTP AUTHENTICATION

Provide an alternative:

**Continue with Email**

The user enters their email address.

The system sends a verification OTP to the user's email.

Example flow:

```text
Enter Email
     ↓
Send OTP
     ↓
Enter OTP
     ↓
Verify OTP
     ↓
Create/Login Account
     ↓
Dashboard
```

OTP requirements:

* 6-digit OTP
* OTP expires after a configurable period such as 5 minutes
* OTP can only be used once
* Limit OTP resend requests
* Limit incorrect OTP attempts
* Store only a secure hash of the OTP where practical
* Never expose OTP in frontend responses
* Never log OTP values in production

Email delivery can use SMTP.

Create configuration:

```env
SMTP_HOST=
SMTP_PORT=
SMTP_USERNAME=
SMTP_PASSWORD=
SMTP_FROM_EMAIL=
```

The email should contain:

```text
AirIndex India

Your verification OTP is: ******

This OTP is valid for 5 minutes.

If you did not request this code, please ignore this email.
```

# 25. INDEX ENGINE

Implement:

```text
APIx(t) =
Σ(Wi × Pi,t / Pi,base) × 100
```

Where:

```text
Wi = route weight
Pi,t = representative fare
Pi,base = base-period fare
```

Route weights must come from the SQL database.

Do not hard-code weights.

Admin should be able to update:

* Route
* Weight
* Base period
* Base fare
* Active status
